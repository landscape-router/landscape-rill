# CN-01 探测行为被误判攻击

> 场景：连通性 ｜ 状态：✅ 已落档（REQ-046） ｜ 复核时机：probe/直连探测实现时

## 问题（现象）

节点对全网候选端点**并发互探**（打洞/连通性验证）——大量短小 UDP 探测的行为特征被网络侧（IDS/风控）**误判为 UDP DoS**：触发网管告警、公司风控封禁，正常节点被误伤。

## 原因

探测没有限速和退避，探测量 = 候选端点数 × 探测频率——行为特征与扫描/攻击无法区分。

## 正确行为

- 探测必须**强制限速 + 指数退避**（不是可选项），收敛行为特征
- 探测包极小、无状态、可丢弃；失败后按退避重试而非并发轰炸

## 复核触发点

probe/直连探测实现时：

1. 是否有限速（默认强制开启）？——已落地：发送侧全局令牌桶 10/s 突发 20 + PONG 生成按源限速（REQ-046）
2. 是否指数退避？——已落地：每端点 miss+1 → `30s×2^miss` 封顶 300s，PONG 确认清零
3. 并发上限是否收敛？——已落地：在途 probe 上限 64（超限拒绝新发送）
