# CN-03 共享/中继节点无用户级认证

> 场景：连通性 ｜ 状态：✅ 已落档 ｜ 复核时机：中继限速/挂靠实现时

## 问题（现象）

共享/中继节点无**用户级认证**——持有网络密钥的任何人都可白嫖中继带宽/转发资源，无配额、无追责；共享节点沦为公共资源池。

## 原因

把"能进网"等同于"被授权使用资源"——中继资源没有独立的授权与计量；共享密钥无法区分使用者。

## 正确行为

- 成员身份逐节点认证 + 吊销（密钥 ≠ 身份）
- 中继/共享资源侧必须有限速（令牌桶），防放大与滥用

## 复核触发点

中继限速/挂靠实现时：

1. relay 侧是否有限速？
2. 成员滥用是否可吊销？
