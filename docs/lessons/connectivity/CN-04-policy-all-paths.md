# CN-04 策略执行必须覆盖全部路径

> 场景：连通性 ｜ 状态：✅ 已落档 ｜ 复核时机：实现组级隔离（v2）时

## 问题（现象）

单网络内按组（多租户）隔离无法执行——三处缺口叠加：

- **中继转发分支无策略检查**：只过滤 Data 包，控制/RPC 信令天然绕过
- **打洞协调信令无组级门控**：任意同网成员可与其他成员协调打洞
- **直连建立后无策略约束**：打洞成功后形成不经服务器的直连通道

结果：即使配置组级 ACL，跨组设备仍可互通，隔离策略形同虚设。

## 原因

策略实现按"模块"而非"路径"覆盖——ACL 只挂在某一层（如 Data 包过滤），转发分支与控制信令漏掉；且直连通道完全绕过服务端，仅凭明文源标识的策略可被伪造。

## 正确行为

- 策略必须覆盖**全部路径**：中继转发分支、打洞协调信令、直连建立后通道
- 隔离必须有加密/授权绑定（仅凭明文源标识可被成员伪造绕过）

## 复核触发点

实现组级隔离（v2）/打洞时：

1. 中继转发是否过策略？
2. 打洞信令是否门控？
3. 直连建立后是否仍受约束？
