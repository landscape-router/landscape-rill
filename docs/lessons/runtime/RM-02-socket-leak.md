# RM-02 连接资源泄漏

> 场景：运行时可靠性 ｜ 状态：需补 ｜ 复核时机：控制面连接管理实现时

## 问题（现象）

TCP socket 泄漏 → **文件描述符耗尽后全网拒接**（长期 DoS）——连接生命周期无管理。

## 原因

连接建立没有上限与超时回收；失败/废弃连接未及时关闭——泄漏是慢性的，等到 EMFILE 才暴露。

## 正确行为

- 连接生命周期管理：**超时回收 + 连接上限**；失败连接必须关闭

## 复核触发点

控制面连接管理实现时：

1. 是否有超时回收？
2. 是否有连接上限？
