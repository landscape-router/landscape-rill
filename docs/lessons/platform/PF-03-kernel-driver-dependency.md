# PF-03 内核驱动依赖灾难

> 场景：平台适配 ｜ 状态：✅ 架构规避 ｜ 复核时机：平台适配时

## 问题（现象）

捆绑**内核驱动**（流量重定向驱动）导致：

- 系统蓝屏（驱动 IRQL 错误，反复崩溃重启）
- 高频驱动加载错误日志刷屏（秒级重复、无法关闭）

数月无修复、无卸载开关——崩溃发生在**系统层**，超出应用可控范围，用户只能手动删驱动或忍受日志风暴。

## 原因

为加速/重定向流量引入内核驱动组件，把稳定性风险放到系统层且无法自愈——一个内核缺陷 = 整机不可用。

## 正确行为

- **纯用户态实现**（用户态转发），零内核驱动依赖
- 任何内核组件引入前必须评估稳定性与卸载路径

## 复核触发点

平台适配时：

1. 是否引入内核驱动/系统组件？
2. 稳定性与卸载是否可控？
