# CP-05 重连无限循环

> 场景：控制面与拓扑同步 ｜ 状态：✅ 已落档 ｜ 复核时机：控制面重连/懒握手实现时

## 问题（现象）

对端不可达时**无限重连**——无上限、无退避：失败端点持续占用资源、刷日志，用户无法配置终止条件。

## 原因

重连逻辑没有退避策略和终止条件——把"永远重试"当成可靠性的实现。

## 正确行为

- 重连必须**指数退避 + 可配置上限**（次数/时间）
- 失败端点不得反复触发握手/探测（防抖）

## 复核触发点

控制面重连/懒握手实现时：

1. 是否有退避？
2. 是否有上限？
3. 是否有防抖（在途握手中不重复发起）？
