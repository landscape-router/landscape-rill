# CP-01 控制接口无认证信息泄露

> 场景：控制面与拓扑同步 ｜ 状态：✅ 已落档 ｜ 复核时机：控制面实现时

## 问题（现象）

控制/RPC 接口无认证监听——**任何机器**可连任意节点管理端口，读取全网拓扑/端点/公钥等敏感信息。

## 原因

控制面默认监听且无认证；以"内网安全"为借口不做接入控制——攻击者一旦进入内网即可全量收集。

## 正确行为

- 控制面必须有认证（TLS + 身份挑战）
- 数据面不暴露裸管理接口：端口分派只认协议首字节，非法输入丢弃

## 复核触发点

控制面实现时：

1. 管理接口是否有认证？
2. 数据面端口是否只认帧/probe（无裸管理接口）？
