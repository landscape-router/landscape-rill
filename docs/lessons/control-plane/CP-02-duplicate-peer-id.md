# CP-02 节点 ID 冲突

> 场景：控制面与拓扑同步 ｜ 状态：✅ 架构规避 ｜ 复核时机：注册流程实现时

## 问题（现象）

节点 ID 由客户端自行分配/协商——**ID 冲突**导致节点意外退出、身份错乱。

## 原因

ID 分配无唯一权威，依赖客户端自觉——分布式环境下必然碰撞。

## 正确行为

- 节点 ID 必须由权威（控制面服务器）**唯一分配**，客户端不得自选

## 复核触发点

注册流程实现时：

1. ID 是否服务端分配？
2. 重复注册是否幂等返回同一 ID？
