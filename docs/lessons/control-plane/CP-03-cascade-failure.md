# CP-03 初始节点崩溃级联故障

> 场景：控制面与拓扑同步 ｜ 状态：✅ 架构规避 ｜ 复核时机：重连/补偿流程实现时

## 问题（现象）

初始节点（拓扑信息的记忆者）崩溃后，子节点**丢失全部对端信息**——拓扑状态只存在内存且无权威恢复源，单点崩溃级联全网失联。

## 原因

拓扑权威放在"最先启动的节点"内存里，没有独立权威 + 恢复机制。

## 正确行为

- 拓扑权威必须独立于任何业务节点（控制面服务器），节点崩溃不影响拓扑
- 断线重连后必须**全量补偿拓扑**（幂等）

## 复核触发点

重连/补偿流程实现时：

1. 拓扑权威是否独立（不依赖业务节点）？
2. 重连后是否全量补偿？
