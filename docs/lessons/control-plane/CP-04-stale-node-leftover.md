# CP-04 失效节点信息残留

> 场景：控制面与拓扑同步 ｜ 状态：✅ 架构收益 ｜ 复核时机：实现 netmap 增量（v2）时

## 问题（现象）

失效节点信息**不清理**——陈旧条目长期残留（如已不存在的链路地址），路由指向失效目标，行为不可预期。

## 原因

拓扑更新只做增量补丁，删除路径没有配套机制；"离线"与"删除"语义混淆。

## 正确行为

- 拓扑以版本为准**整体替换**（全量 = 天然无残留）；增量更新必须配套淘汰策略
- 软离线（可达性标记）与硬删除（条目移除）语义分离

## 复核触发点

实现 netmap 增量（v2）时：

1. 删除路径是否配套？
2. 增量更新是否以版本为准、无残留？
