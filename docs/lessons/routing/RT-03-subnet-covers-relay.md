# RT-03 子网代理覆盖中继端点

> 场景：路由引擎与转发 ｜ 状态：✅ 已落档 ｜ 复核时机：路由引擎实现时

## 问题（现象）

子网代理公告**覆盖中继/服务器公网地址**——外层封装包（目标 = 中继公网 IP）被路由引擎按公告前缀卷回隧道自身，形成**循环断链**。

## 原因

公告前缀与端点地址空间重叠，且封装后的报文又走了一遍路由决策——自指循环未被路径语义隔离。

## 正确行为

- 封装完成的外层包**直发物理接口，不再经过路由引擎**（强制路径语义）
- 公告前缀与端点重叠要有闭环校验/容忍设计

## 复核触发点

路由引擎实现时：

1. 外层包是否直发物理接口（不经 LPM）？
2. 前缀/端点重叠是否闭环？
