# RT-01 公告前缀自指

> 场景：路由引擎与转发 ｜ 状态：✅ 已落档 ｜ 复核时机：前缀公告流程实现时

## 问题（现象）

公告的代理网段**包含公告者自身地址**——发往自身的流量被封装进隧道，再次被路由引擎命中→再次封装，形成**自指黑洞循环**。

## 原因

公告校验只查前缀合法性，不查"前缀是否包含自身"——拓扑自指未被识别。

## 正确行为

- 公告前缀必须**排除公告者自身地址**（tun0/物理接口地址）
- 校验在管理面（白名单）完成，不依赖客户端自觉

## 复核触发点

前缀公告流程实现时：

1. 校验是否排除公告者自身地址？
2. 白名单是否在管理面强制？
