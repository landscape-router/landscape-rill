# RT-02 多路由表处理错乱

> 场景：路由引擎与转发 ｜ 状态：✅ 架构规避 ｜ 复核时机：路由引擎实现时

## 问题（现象）

隧道软件操作系统多路由表（策略路由/自定义表），软重连或状态刷新时**误删默认路由 → 整机断网**。一次误操作全局不可达，且与内核路由管理耦合过深、难以调试。

## 原因

把转发决策下沉到内核路由表，用户态与内核状态同步存在竞态；状态机错误直接破坏系统网络。

## 正确行为

- 转发决策全部在**用户态完成**（单一真相源），内核只做最小参与（一张 TUN + 少量静态路由）
- 禁止用户态程序改写系统路由表

## 复核触发点

路由引擎实现时：

1. 是否碰内核路由表？
2. 路由真相是否唯一（用户态）？
