# KC-03 域名解析无背压

> 场景：密钥与配置管理 ｜ 状态：✅ 已落档 ｜ 复核时机：配置解析实现时

## 问题（现象）

配置中域名解析**无背压**——解析失败持续重试占满 CPU，形成解析风暴（系统 DNS 客户端持续高占用）。

## 原因

解析调用没有缓存和退避——失败即立即重试，无背压控制，一次不可达的域名拖垮 CPU。

## 正确行为

- 域名解析必须**缓存 + 指数退避**，禁止无背压循环解析

## 复核触发点

配置解析实现时：

1. 是否有缓存？
2. 是否指数退避？
3. 是否存在无背压循环？
