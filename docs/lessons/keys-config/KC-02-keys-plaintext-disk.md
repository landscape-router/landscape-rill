# KC-02 密钥明文落盘

> 场景：密钥与配置管理 ｜ 状态：需补 ｜ 复核时机：配置解析/密钥存储实现时

## 问题（现象）

网络凭据/私钥**明文存配置文件**——文件泄露即全部密钥泄露，且无权限保护意识。

## 原因

配置与密钥混在同一文件，且无权限/加密要求——存储安全被当作"文件系统的事"。

## 正确行为

- 密钥文件权限收紧（如 0600）+ **可选加密存储**
- 密钥与普通配置分离管理

## 复核触发点

配置解析/密钥存储实现时：

1. 密钥文件权限是否收紧（0600）？
2. 是否支持加密存储？
