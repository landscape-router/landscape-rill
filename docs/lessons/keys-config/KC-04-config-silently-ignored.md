# KC-04 配置静默失效

> 场景：密钥与配置管理 ｜ 状态：✅ 已落档 ｜ 复核时机：配置实现时

## 问题（现象）

白名单/配置项**反复静默失效**——配置不生效且无任何感知（含安装脚本与二进制不一致导致的配置丢失），安全策略形同虚设。

## 原因

配置加载"尽力而为"：非法/缺失配置被静默忽略而非显式报错——用户以为生效了，实际没有。

## 正确行为

- 配置**加载即校验**：全部配置项校验，非法配置拒绝启动（fail-closed）
- 禁止静默忽略任何配置项

## 复核触发点

配置实现时：

1. 是否加载即校验（非法配置拒绝启动）？
2. 是否存在静默忽略路径？
