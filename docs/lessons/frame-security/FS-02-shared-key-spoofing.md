# FS-02 共享网络密钥可互伪

> 场景：数据面协议与认证 ｜ 状态：✅ 已落档 ｜ 复核时机：实现密钥体系/握手时

## 问题（现象）

全网共享一份网络密钥作为身份/加密基础：

- 任何持钥者可**伪装任意节点**通信（互伪）
- 密钥静态长期有效 → **无前向保密**，历史流量在密钥泄露后全部可解密

## 原因

用"共享秘密"代替"身份体系"——把"能进网"和"你是谁"混为一谈；静态共享密钥没有"一次一密"的隔离能力。

## 正确行为

- 身份必须逐节点绑定（公钥/证书），共享密钥只能做入网门槛，不能做身份
- 会话密钥必须逐对派生 + 握手派生（前向保密），禁止长期静态密钥加密流量
- 身份绑定必须有权威签发，防中间人伪造绑定

## 复核触发点

实现密钥体系/握手时：

1. 会话密钥是否逐对派生？
2. 是否有前向保密（握手派生，非静态密钥）？
3. 身份是否有权威绑定？
