# FS-07 默认加密算法选择失当

> 场景：数据面协议与认证 ｜ 状态：✅ 已落档 ｜ 复核时机：加密算法相关改动时

## 问题（现象）

默认算法选择未纳入安全评估——默认使用弱算法，更强的候选未被采纳。默认值即全网安全基线：选错 = 全网暴露，且用户无感知（默认配置 = 公开配置，谁都能看到）。

## 原因

算法选择凭"顺手"而非安全评估；默认值没有安全评审关卡。

## 正确行为

- 默认算法必须经过安全评估，选现代 AEAD（如 ChaCha20-Poly1305）
- 算法不可用即 fail-closed（拒绝启动），无降级路径

## 复核触发点

加密算法相关改动时：

1. 默认算法是否为现代 AEAD？
2. 是否存在弱算法回退路径？
