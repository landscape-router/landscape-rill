# FS-03 加密后端不可用时静默降级

> 场景：数据面协议与认证 ｜ 状态：✅ 已落档 ｜ 复核时机：依赖引入/构建配置变更时

## 问题（现象）

加密后端不可用（构建时未启用/平台缺支持）时，协议**静默降级**为弱加密甚至明文等价实现——无完整性、可破译，客户端无任何感知，安全强度取决于构建环境。

## 原因

把加密当作"可选增强"而非"强制基线"：用构建标志/特性开关决定是否加密，失败路径没有 fail-closed——安全变成"碰运气"。

## 正确行为

- 加密是强制基线：算法不可用即**拒绝启动组网**，无降级路径（fail-closed）
- 禁止"依赖缺失就换弱算法"的任何分支；依赖缺失必须显式报错

## 复核触发点

依赖引入/构建配置变更时：

1. 依赖缺失是否 fail-closed（拒绝启动）？
2. 是否存在任何条件分支降低加密强度？
