# FS-08 共享入口无强制鉴权

> 场景：数据面协议与认证 ｜ 状态：✅ 已落档 ｜ 复核时机：路由引擎/入口实现时

## 问题（现象）

共享入口（代理/出口节点）无强制鉴权——公共场景任何人可把节点当出口：带宽被白嫖、出口流量无法追责、可能被用于恶意活动。

## 原因

入口鉴权被当作"可选配置"默认放行；隐含假设"能进网的人都是好人"。

## 正确行为

- 共享入口必须有鉴权（默认拒绝）；信任边界显式声明（如 LAN 侧可信、网络侧逐身份认证）
- 成员身份逐节点认证 + 吊销；入口策略可审计

## 复核触发点

路由引擎/入口实现时：

1. 入口默认放行还是拒绝？
2. 信任边界是否显式声明？
3. 成员身份是否逐节点认证 + 可吊销？
