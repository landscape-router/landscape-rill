# FS-06 内部名称解析使用真实可解析域名

> 场景：数据面协议与认证 ｜ 状态：✅ 已落档 ｜ 复核时机：DNS 分类语义实现时

## 问题（现象）

内部网络使用**真实可解析的域名**做设备命名——公网可解析这些名字（甚至被劫持指向恶意 IP），用户被钓鱼、被误导连接错误节点。

## 原因

图省事用通用域名体系，忽略内部命名空间必须隔离、不可被公网解析的安全要求。

## 正确行为

- 内部命名必须使用**保留后缀/不可解析域名**，禁止真实可解析域名
- 解析代理对未知后缀一律走上游，不泄漏内部查询

## 复核触发点

DNS 分类语义实现时：

1. 内部后缀是否不可解析（保留域名）？
2. 未知后缀是否不泄漏内部查询？
