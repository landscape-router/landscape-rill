# FS-04 加密路径旁路

> 场景：数据面协议与认证 ｜ 状态：✅ 已落档（硬规则）｜ 复核时机：设计/新增任何包类型或通道时

## 问题（现象）

存在绕过加密的**旁路通道**——"明文传输模式"、"经代理通道穿透加密"等。任一流量路径能绕过加密，整体安全承诺即被打破：路径完整性依赖"全部路径都加密"的约定，一个口子全盘失效。

## 原因

加密按"模式"而非"路径"实现——把加密做成可开关的选项，新增路径时容易漏加，且用户可主动关闭。

## 正确行为

- **硬规则：任何新增包类型/通道不得绕过 AEAD**；不存在"模式开关"改变加密强度
- 安全是全部路径的固定属性，不是逐路径可选项

## 复核触发点

设计/新增任何包类型或通道时：

1. 新路径是否强制 AEAD？
2. 是否存在明文模式/降级开关？
