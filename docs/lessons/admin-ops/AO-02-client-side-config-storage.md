# AO-02 关键配置存客户端本地存储

> 场景：管理面与运维 ｜ 状态：✅ 已落档 ｜ 复核时机：WebUI/管理面实现时

## 问题（现象）

关键配置存**客户端本地存储**（浏览器 localStorage 等）——容量上限导致数据丢失，且不可审计、不可集中管理。

## 原因

管理功能在客户端实现，服务端没有持有配置真相——配置的生命周期跟随浏览器而非服务。

## 正确行为

- 关键配置只存**服务端**（权威），客户端/WebUI 不持有持久配置

## 复核触发点

WebUI/管理面实现时：

1. 配置真相是否在服务端？
2. WebUI 是否持久化配置？
