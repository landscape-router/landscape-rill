# AO-03 管理接口越权

> 场景：管理面与运维 ｜ 状态：需补 ｜ 复核时机：管理面/WebUI 实现时

## 问题（现象）

管理 API **越权**——任意登录用户可读所有设备敏感数据（token/凭据），授权模型缺失。

## 原因

认证与授权混淆——"能登录"即"能看所有"。

## 正确行为

- 管理面必须有**授权模型**（按用户/角色分权），越权场景必须测试

## 复核触发点

管理面/WebUI 实现时：

1. 授权模型是否存在（角色/分权）？
2. 越权测试是否覆盖敏感数据读取场景？
