# AO-04 日志风暴

> 场景：管理面与运维 ｜ 状态：✅ 已落档 ｜ 复核时机：运维基线（P2）实现时

## 问题（现象）

日志无上限**撑爆磁盘**；日志级别配置不生效——故障时反而因为日志把自己打挂（故障+日志双重风暴）。

## 原因

日志没有容量上限与限速；级别配置没有生效性验证——配置了等于没配置。

## 正确行为

- 日志**限速 + 轮转/容量上限**
- 日志级别配置必须有**生效性验证**

## 复核触发点

运维基线（P2）实现时：

1. 是否限速？
2. 是否轮转 + 容量上限？
3. 级别配置是否验证生效？
