# AO-06 发布产物与源码一致性

> 场景：管理面与运维 ｜ 状态：需补 ｜ 复核时机：运维基线（P2）/ CI 发布流水线实现时

## 问题（现象）

**发布二进制与开源源码不一致**；即使开启私有化部署仍外连**硬编码默认服务器/域名**（且源码中查不到这些域名）——用户无法审计"我跑的东西是否等于我看到的代码"，供应链信任缺失。

## 原因

发布流程不可复现；产物包含源码外的行为（硬编码默认服务器）；无产物一致性校验机制。

## 正确行为

- **可复现构建** + 发布产物与源码一致性校验（可复现/签名/产物哈希）
- 禁止硬编码默认服务器行为——**配置即唯一来源**

## 复核触发点

运维基线（P2）/ CI 发布流水线实现时：

1. 构建是否可复现？
2. 产物是否可校验（签名/哈希）？
3. 是否存在硬编码默认行为？
