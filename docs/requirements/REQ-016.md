# REQ-016 安全审查修正（key_dst 边界 + 成员能力矩阵）

> 类型：决策 ｜ 状态：✅ merged ｜ 提出：2026-08-15 ｜ 合并：2026-08-15
> 去向：FRAME_HEADER §2.3/§5 ｜ 验收场景：SEC-03 / SEC-04 / SEC-09 / SEC-10

## 动机

安全审查发现 `key_dst` 实为全网可得，route_mac 不认证源，需要修正安全边界表述与兜底机制。

## 决策摘要

`key_dst` 全网可得、route_mac 只防外部篡改**不认证源**（成员可伪造 from_node_id，靠 AEAD + 握手层兜底）；新增握手双保险（msg1 携带目标 node_id + 身份绑定交叉验证）；§5 安全表区分非成员/成员攻击能力 + 成员能力矩阵（内容层锁死/握手层可中断不可冒充/路由层 DoS 等价）；coordinator 主密钥单点与成员 DoS 极限为已接受的固有设计。
