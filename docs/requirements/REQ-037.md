# REQ-037 v1 存储后端选择

> 类型：决策 ｜ 状态：✅ merged ｜ 提出：2026-08-15 ｜ 合并：2026-08-31 ｜ 去向：CONTROL_PLANE §4.1 ｜ 验收场景：CTL-16 ｜ 相关教训：KC-02（存储文件权限 0600）

## 动机

coordinator 持久状态（注册表/身份绑定/主密钥/吊销列表/netmap 版本/PathMap）需要存储后端（CONTROL_PLANE §4.1）；约束：Raft 日志兼容（P2）+ 不引入 C 依赖。

## 决策摘要

后端定 **redb**（Rust 原生、单文件、无 C 依赖；sqlite 否决——数据形态全为主键点查，关系能力零收益）。持久状态**整快照原子写**（单键，redb 事务），写穿透点 = register / set_endpoints / request_paths / revoke / rotate_master_key；一次性 auth key 消费 tombstone 落盘（重启/重载不复活）；损坏/不一致 → 拒绝启动（fail-closed）；`storage_path` 仅启动读取（None = 纯内存）；存储文件权限 0600（KC-02）。

## 验收标准

- 持久状态重启后可恢复；损坏状态不被猜测重建
