## 动机

同时接入 mesh/dn42/tailscale 多网络，需要统一转发汇合点。

## 决策摘要

**单 TUN + 用户态路由**；dn42 用 boringtun（不用内核 wg）+ 自研 BGP 最小集；dn42 路由仅 rill ext 持有（不进 mesh netmap）；mesh exit 仅透传不 NAT（WAN NAT 兜底）。
