# REQ-010 多网络隔离（协议无感多租户）

> 类型：需求 ｜ 状态：✅ merged ｜ 提出：2026-08-15 ｜ 合并：2026-08-15
> 去向：CONTROL_PLANE §1.5 ｜ 验收场景：CTL-09 / SEC-21 ~ SEC-25

## 动机

一个 coordinator 服务多个默认互不可见的隔离网络（家庭/公司/测试）。

## 决策摘要

coordinator 内部按网络分域：network_id/主密钥/auth key 空间/netmap 独立；auth key 生成时绑定网络（注册即归域）；网络间默认隔离，互通 = 联邦 v2（网络 = 联邦最小单元）。
