# REQ-035 广播 opt-in（按需下发 broadcast_key）

> 类型：需求 ｜ 状态：✅ merged ｜ 提出：2026-08-30 ｜ 合并：2026-08-30
> 去向：CONTROL_PLANE §3.1/§3.3 / FRAME_HEADER §2.6 ｜ 验收场景：FRM-08 / CTL-14

## 动机

广播平时不参与（仅 ND/mDNS 等组播场景触发），"不想收 L2 的主机"真正缺口 = 发送侧仍全量泛洪 + keydist 全量下发 broadcast_key。

## 决策摘要

能力位表新增 `broadcast=0x20`（opt-in）；keydist 按需下发（仅向能力位含 broadcast 的节点携带 broadcast_key，未 opt-in 不填充）；泛洪目标收窄 = endpoint_table 中除自己与源外且 opt-in 的端点（发送与转发双侧过滤，无能力记录按未 opt-in fail-closed）；连带清理（flags 注释去 L2 预留、删恒 None 的 key_dist(0xFFFFFFFF) 死分支）；e2e capabilities 1 → 33。

## 验收标准（草案，实现待落地）

- FRM-08：未 opt-in 节点不收 broadcast_key、泛洪只达 opt-in 端点（当前为 v0.7 全量下发语义，部分覆盖）
- CTL-14：keydist 按能力位按需下发（待实现）
