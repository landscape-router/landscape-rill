# REQ-020 ACL v2 预留落档

> 类型：决策 ｜ 状态：✅ merged ｜ 提出：2026-08-15 ｜ 合并：2026-08-15
> 去向：CONTROL_PLANE §3.10 / ROUTE_ENGINE §2/§3 ｜ 验收场景：SEC-28

## 动机

零信任式逐请求授权需要提前预留接入点，避免 v2 重构转发链。

## 决策摘要

①转发链固定 `LPM 命中 → 策略检查 → 封装`，v1 恒放行、实现禁写死；②源身份约束：ACL 只做目标节点侧裁决（route_mac 不认证源）；③netmap version 一版本两用承载策略版本；④`acl` 能力位划归 v1 恒 false；⑤Policy 消息族组空间预留；⑥tenancy 验证断言；⑦管理面形态定稿时纳入策略模型。
