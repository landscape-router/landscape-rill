# REQ-004 控制面 v0.1 中心化 coordinator

> 类型：决策 ｜ 状态：✅ merged ｜ 提出：2026-08-15 ｜ 合并：2026-08-15
> 去向：CONTROL_PLANE §1/§3.2/§3.4~§3.7/§4/§5/§7 ｜ 验收场景：CTL-01

## 动机

需要唯一权威源保证拓扑/密钥一致性；去中心化一致性成本高、风险大。

## 决策摘要

中心化 coordinator（唯一权威源）+ TLS/protobuf 长连接 + auth key 预授权 + netmap 全量带版本号；Raft 兼容设计（幂等/软硬状态分离，P2 演进）；v1 单机、coordinator 作为 mesh 节点角色运行；联邦 = v2 特性 + v1 三钩子（§7）。
