# REQ-036 auth key 格式与生成规范

> 类型：需求 ｜ 状态：✅ merged ｜ 提出：2026-08-15 ｜ 合并：2026-08-31 ｜ 去向：CONTROL_PLANE §3.12/§6 ｜ 验收场景：ADM-04 ~ ADM-05

## 动机

auth key 需要统一的格式、生成与分发规范（一次性/可复用/tag/过期语义见 CONTROL_PLANE §6）；生成过程不落日志/命令行（教训 AO-01/AO-02）。

## 决策摘要

**格式 `lrk-<network>-<secret>`**：`lrk` 固定前缀（格式校验拒绝）、`<network>` 配置声明的网络标识（归域绑定）、`<secret>` = 32B CSPRNG → base32（RFC 4648 无填充）。生成 = `lrill authkey` 子命令（纯本地、不依赖 master_key、输出仅 stdout）。过期 = reusable key 带 `expires_at` 注册时校验；吊销 = 配置移除 + SIGHUP 重载（§3.12）。
