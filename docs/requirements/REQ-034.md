# REQ-034 路径服务与 key_path 路径授权

> 类型：需求 ｜ 状态：✅ merged ｜ 提出：2026-08-30 ｜ 合并：2026-08-30
> 去向：CONTROL_PLANE §3.11 / FRAME_HEADER §9 ｜ 验收场景：CTL-15

## 动机

借鉴 SCION Path Service 思想：netmap 描述"节点是谁"，PathMap 描述"节点之间怎么到"；同时把 key_dst 的"全网共享"信任域收窄为"路径参与者"。

## 决策摘要

NodeMap/PathMap 分离；PathRequest/Response/Update/Withdraw/Probe 消息族（v1.5 单 coordinator）；每目标 2~4 候选路径 + flow hash + 快速切换 + 路径生命周期；数据面帧头固定 8B path_id（42B，纳入 route_mac/AAD），route_mac 改用 `key_path = KDF(主密钥, path_id, path_epoch)`；`path_id=0` = 默认路径 key_dst（REQ-066 统一 42B 帧头，v1 兼容语义已删）；路径集合 = 路径级 ACL；不做逐跳 hop key。
