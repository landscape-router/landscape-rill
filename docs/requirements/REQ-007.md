# REQ-007 mesh 连通性定稿（端点探测/直连/三层中继）

> 类型：决策 ｜ 状态：✅ merged ｜ 提出：2026-08-15 ｜ 合并：2026-08-15
> 去向：CONNECTIVITY §2/§3/§4/§5 ｜ 验收场景：CON-01 ~ CON-06

## 动机

NAT 后的节点需要端点发现与直连/中继通道。

## 决策摘要

端点探测 = coordinator UDP 回显（STUN 式）；直连 v1 = disco 式简单互探（专用 probe 小包）+ 中继兜底；**三层中继模型**（coordinator 兜底 + 自愿节点 opt-in 扩容 + 独立 relay 可选），全部零协议改动。
