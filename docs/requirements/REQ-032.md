# REQ-032 IPv6 双栈与组播泛洪

> 类型：需求 ｜ 状态：✅ merged ｜ 提出：2026-08-16 ｜ 合并：2026-08-16
> 去向：FRAME_HEADER §2.6/§3.1 ｜ 验收场景：FRM-08 / FRM-10

## 动机

P1 闭环需要 IPv6 双栈；L2 组播（ND/RS/mDNS）需要跨节点送达，单播转发到不了。

## 决策摘要

广播密钥三件套激活（type=广播/to=0xFFFFFFFF/broadcast_key）：AEAD 与 route_mac 均用 broadcast_key、每源独立 seq + 重放窗口、relay 泛洪（去重 30s + ttl + 不向源回泛 + 令牌桶 64/16/s）、泛洪目标含无会话端点；LAN 侧组播包触发泛洪；IPv6 走 rtnetlink（tun crate 无 netlink feature）；POINTOPOINT TUN 内核不发 NS（单播直接懒握手）；e2e 双栈 ping6 通过；组播指纹防再泛洪（RS 风暴踩坑）。

## 验收标准（已满足）

- FRM-08：广播泛洪去重/限速/opt-in 语义单测闭环
- FRM-10：e2e IPv4 + IPv6 ping 0% 丢包
