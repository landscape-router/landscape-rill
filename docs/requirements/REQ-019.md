## 动机

评估浏览器/嵌入式编译形态的投入产出。

## 决策摘要

**不做 WASI 专门工程**（浏览器无 UDP/TUN，无法成为 rill 节点；手机已被官方 app 覆盖；其他端走 Rust 原生编译）；Web 纯终端挂账 v3 候选（REQ-041）；核心协议模块保持 I/O 无关（frame/control/route 不混 tokio/io），将来 wasm 化零重构。
