# REQ-008 前缀公告机制

> 类型：需求 ｜ 状态：✅ merged ｜ 提出：2026-08-15 ｜ 合并：2026-08-15
> 去向：CONTROL_PLANE §3.8 / ROUTE_ENGINE §3 ｜ 验收场景：CTL-10 / CTL-11

## 动机

节点背后的 LAN/前缀需要路由进 mesh，供全网可达。

## 决策摘要

netmap 内嵌 `routes[]`（tailscale subnet routes 式）；coordinator 白名单校验；允许同一前缀多节点公告（多网关冗余）；禁止过短前缀（IPv4 < /8、IPv6 < /32，默认出口走 exit）；离线自动撤销。
