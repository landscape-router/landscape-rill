# REQ-069 Web 管理端点写操作（吊销）

- 类型：需求
- 状态：✅ merged
- 提出日期：2026-10-01
- 合并日期：2026-10-01
- 去向：CONTROL_PLANE §3.14
- 验收场景：ADM-08（tests/admin.md）

## 动机

管理面写路径现状 = 配置文件 + SIGHUP（REQ-038）或库 API，无运维可用的远程操作面。`GET /status`（REQ-051）只覆盖观察面；吊销这类**操作型动作**（不在配置文件表达、需要即时生效）没有远程入口。CONTEXT §9 挂账项 5 将 Web 管理面与自研 ts2021 服务端同批，该批次已闭——现在落地。

## 决策摘要

v1 写面 = 吊销一项（`POST /admin/revoke`），落在 REQ-051 status 监听器上、同 Bearer 认证面（CP-06 同等鉴权）+ 审计日志；配置权威边界不变（REQ-038/040）：HTTP 面只承载操作型动作，配置态与主密钥轮换仍走配置文件；独立 WebUI 与更多写端点按运维需求增量评估。

- lessons 复核（合并时）：AO-07（吊销即时生效经单一写路径保留）、CP-06（破坏性端点同等鉴权 + 请求体认证后解析）
