# REQ-038 管理面形态（前缀公告白名单配置）

> 类型：需求 ｜ 状态：✅ merged ｜ 提出：2026-08-15 ｜ 合并：2026-08-31 ｜ 去向：CONTROL_PLANE §3.12 ｜ 验收场景：ADM-01 ~ ADM-03

## 动机

coordinator 需要配置前缀公告白名单（CONTROL_PLANE §3.8）、管理 auth key（REQ-036）与策略模型（REQ-020）。形态定稿时纳入 ACL v2 策略模型。

## 决策摘要

**v1 形态 = 配置文件为唯一权威 + 库 API 执行面分离**：`CoordConfig`（解析 + 校验，fail-closed 加载即校验）独立于运行时；`CoordinatorServer::from_config / apply_config` 为库 API（函数调用生效），其他项目可引入 crate 直接调用；CLI/未来 Web 为薄调用层。变更生效 = SIGHUP 重载（增量应用、不中断在途连接、失败保持旧配置）。白名单注册时逐条校验，不匹配整体拒绝（`RouteNotAllowed`）。
