# REQ-017 安全审查落档（TLS 信任锚/KDF/心跳帧/限速）

## 动机

安全审查 #14 各项要求的落档。

## 决策摘要

TLS 信任锚 = 公网证书为主（内网可选自签 CA 预置）；算法 fail-closed（无降级路径）+ KDF = HKDF-SHA256；管理面无默认凭据 + 配置加载即校验；握手报文规格（prologue = network_id ∥ 版本、msg1 带目标 node_id、msg3 带身份绑定、rekey 双窗口交叠）；心跳帧规格（AEAD 空载荷，仅已建会话对）；coordinator 回显按源限速；解析 fail-closed 强制；全端口可达 = 有意语义（ACL v2）；前缀与端点重叠无害闭环；mesh DNS 后缀 `.mesh`。
