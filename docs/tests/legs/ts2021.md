## TSL-04 自研客户端连自建服务

- 关联 REQ：REQ-021
- 测试层：集成 + e2e
- 状态：`已覆盖`

- 说明：控制面 + 数据面全链路——lrill 自研客户端经 TLS → `GET /key` → controlhttp 升级（msg1-in-header）→ Noise IK → early payload → HTTP/2 → `/machine/register`（auth key）→ MapRequest 长轮询 netmap（DiscoKey + Lite 端点上报，TS2021_LEG §3.3.1）→ DERP 连接（node key 身份）→ boringtun WG 会话；e2e 断言 **lrill→node-c WG ping 与 node-c→lrill 反向 ping（内核 ICMP 全路径）双向互通**。单测 29 个含独立 Go 语义对照（snow LE/BE nonce、nacl box 布局、ICMP checksum 内核级校验）

## TSL-05 subnet router 广播

- 关联 REQ：REQ-021
- 测试层：集成 + e2e
- 状态：`已覆盖`
- 证据：e2e/ts2021_runtime/run.sh、rill-node/src/runtime/ts2021.rs、rill-node/src/runtime/tests.rs
- 说明：rill-ext（rilld：mesh + land0 + ts2021 腿）把 mesh `routes[]` 汇总（rill-b 公告的 10.42.0.0/24，netmap 联动 → poke 重发长轮询）与自家 LAN（10.43.0.0/24 静态）广播进自建 headscale，审批后 node-c（官方 tailscaled `--accept-routes`）ping 通 mesh 资源与 rill-ext LAN——完整路径 node-c tailscale0 → WG(DERP) → 解包 → 引擎 Mesh 路由 → mesh 帧 → rill-b land0 内核应答 → 回程 mesh → tailnet /32 → node-c。单测覆盖 netmap 路由注入/全量替换（`ts2021_netmap_routes_injected_and_replaced`）与 tailnet 入站 transit（`tailnet_ingress_transits_to_mesh_and_reflection_dropped`）。回程前提：rill-ext 把 tailnet 前缀 100.64.0.0/10 公告进 mesh（announce_routes）+ rill-b 内核回程路由 → land0

## TSL-06 exit 使用

- 关联 REQ：REQ-021
- 测试层：集成 + e2e
- 状态：`已覆盖`
- 证据：e2e/ts2021_register/run.sh、rill-ts2021/src/tailcfg.rs、rill-ts2021/src/bin/ts2021-probe.rs
- 说明：lrill 经 node-c（官方 exit node）转发 ping 非本网地址往返互通（EXIT_PING_OK）——完整路径 WG 封装 → node-c tstun 包过滤放行 → 内核转发 → nftables MASQUERADE → 回程 conntrack 反 NAT → WG 回包。e2e 拓扑：独立 docker 网络网关作目标（目标子网经 `--advertise-routes` 显式广播 + headscale 审批——tailscaled 对 0.0.0.0/0 过滤剔除本机直连网段与 RFC1918（guest-wifi 语义），docker 网段全是 RFC1918 必须显式广播，TS2021_LEG §3.3.1）；probe `--ping-exit` 独立 ident 区分回包，`NetPeer::first_ipv4` 只取 /32 主机路由（exit peer 的 AllowedIPs 含 0.0.0.0/0）

## TSL-07 exit 被用作

- 关联 REQ：REQ-021
- 测试层：集成 + e2e
- 状态：`已覆盖`
- 证据：e2e/ts2021_runtime/run.sh、e2e/ts2021_runtime/entry-rill.sh
- 说明：node-c `tailscale set --exit-node=<rill-ext>`（`advertise_exit: true` 广播 0.0.0.0/0 + ::/0，headscale 审批）后 ping 独立 docker 网络网关（192.168.245.1，node-c 不接入该网络）往返互通——完整路径 node-c → WG(DERP) → 解包 → 引擎未命中 → 写 land0 → 内核转发（ip_forward + rp_filter=0）+ iptables MASQUERADE → 回程 conntrack 反 NAT → 内核 100.64.0.0/10 路由回 land0 → 用户态 tailnet /32 → node-c（RTT ~103ms = DERP 双跳中继）
