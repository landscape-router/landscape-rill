## TSL-05 subnet router 广播

- 说明：rill-ext（rilld：mesh + land0 + ts2021 腿）把 mesh `routes[]` 汇总（rill-b 公告的 10.42.0.0/24，netmap 联动 → poke 重发长轮询）与自家 LAN（10.43.0.0/24 静态）广播进自建 headscale，审批后 node-c（官方 tailscaled `--accept-routes`）ping 通 mesh 资源与 rill-ext LAN——完整路径 node-c tailscale0 → WG(DERP) → 解包 → 引擎 Mesh 路由 → mesh 帧 → rill-b land0 内核应答 → 回程 mesh → tailnet /32 → node-c。单测覆盖 netmap 路由注入/全量替换（`ts2021_netmap_routes_injected_and_replaced`）、tailnet 入站 transit（`tailnet_ingress_transits_to_mesh_and_reflection_dropped`）、汇总门控（`set_mesh_routes_gated_to_announcer_shape`）、直发源受理性（`accepts_source_scopes_to_assigned_and_advertised`）、回程源约束 LPM 顺延（`unacceptable_tailnet_source_falls_to_mesh_return`）与本机前缀本地投递（`mesh_ingress_to_local_prefix_delivers_locally`，ROUTE_ENGINE §3）。回程前提：rill-ext 把 tailnet 前缀 100.64.0.0/10 公告进 mesh（announce_routes）+ rill-b 内核回程路由 → land0

## TSL-06 exit 使用

- 关联 REQ：REQ-021

- 状态：`已覆盖`
- 证据：e2e/ts2021_register/run.sh、rill-ts2021/src/tailcfg.rs、rill-ts2021/src/bin/ts2021-probe.rs

## TSL-07 exit 被用作

- 状态：`已覆盖`
- 证据：e2e/ts2021_runtime/run.sh、e2e/ts2021_runtime/entry-rill.sh
- 说明：node-c `tailscale set --exit-node=<rill-ext>`（`advertise_exit: true` 广播 0.0.0.0/0 + ::/0，headscale 审批）后 ping 独立 docker 网络网关（192.168.245.1，node-c 不接入该网络）往返互通——完整路径 node-c → WG(DERP) → 解包 → 引擎未命中 → 写 land0 → 内核转发（ip_forward + rp_filter=0）+ iptables MASQUERADE → 回程 conntrack 反 NAT → 内核 100.64.0.0/10 路由回 land0 → 用户态 tailnet /32 → node-c（RTT ~103ms = DERP 双跳中继）

## TSL-11 增量 peer 帧应用

- 关联 REQ：REQ-067
- 测试层：集成 + e2e
- 状态：`已覆盖`
- 证据：e2e/ts2021_runtime/run.sh、rill-ts2021/src/tailcfg.rs、rill-node/src/runtime/ts2021.rs
- 说明：两段断言——① node-c（官方 tailscaled，状态持久）容器重启 → 同 machine key 重注册，我侧旧 WG 会话失效经 rekey（≤90s）重建，ping 10.43.0.1/10.42.0.1 恢复（e2e 同时实证：重启自身不产生增量帧——同 key 同端点 = 服务端视角无变更）；② peer 增删在**持有流**上实时传播（v0.5 起自研服务端具备中流推送，REQ-068）——node-d（官方 tailscaled）入网 → rill-ext 长轮询流同流收到 PeersChanged 增量帧（`netmap delta applied: +1`，无重轮询/重启）；e2e 注入驱逐（`RILL_E2E_TS2021_EVICT_NODE` env + `/tmp/rill-e2e-evict/<hostname>` marker 文件）→ PeersRemoved（`+0 -1`）。headscale 0.29 时代无中流推送的实证（强制重轮询模拟）已被替换。单测：解码 `map_response_decodes_incremental_peer_frames`（缺省 ≠ 空集坍缩）+ 合并 `apply_delta_merges_incremental_peer_frames`（upsert 保 hex 身份 / patch 按 nid / removed 清理 / key 轮换迁移）+ 服务端持有流增量 `held_stream_receives_delta_frames`

## TSL-12 自研 ts2021 服务端

- 关联 REQ：REQ-068
- 测试层：集成 + e2e
- 状态：`已覆盖`
- 证据：rill-ts2021/src/server/mod.rs、rill-ts2021/src/server/control.rs、rill-ts2021/src/server/netmap.rs、rill-ts2021/src/server/registry.rs、rill-ts2021/src/server/derp.rs、rill-ts2021/src/server/tests.rs、rilld/src/ts2021_run.rs、e2e/ts2021_runtime/run.sh
- 说明：进程内集成（`server::tests`，7 场景）——/key 公钥闭环、注册准入（坏 auth key = 200 + Error 载荷）与幂等（同 machine 保 nid/地址）、全量 netmap 形状（DERPMap 客户端可解析 + 已审批路由进对端 AllowedIPs）、持有流增量帧（注册 → PeersChanged、驱逐 → PeersRemoved）、Lite 更新路由覆写与白名单丢弃（allow_exit 独立裁决默认路由）、跨机器冒用 node key → 401、DERP 双客户端中继。e2e（ts2021_runtime v0.12 起）——**官方 tailscaled（node-c/node-d）与 lrill 双形态客户端同 tailnet 接入自研服务端**：chalpub early payload、RegisterResponse 整型 LoginID、MapRequest.Compress="zstd"（帧体 zstd 封装，自研 raw-block 编码器）三处官方客户端线格式兼容；白名单自动审批 + allow_exit 替代 headscale CLI 审批步骤。headscale 兼容参照保留于 ts2021_register（TSL-04/06/08/10）与 p0_tailscale（TSL-01）
