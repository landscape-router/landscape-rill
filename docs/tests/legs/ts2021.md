## TSL-04 自研客户端连自建服务

- 关联 REQ：REQ-021
- 测试层：集成 + e2e
- 状态：`已覆盖`
- 证据：e2e/ts2021_register/run.sh
- 说明：控制面 + 数据面全链路——lrill 自研客户端经 TLS → `GET /key` → controlhttp 升级（msg1-in-header）→ Noise IK → early payload → HTTP/2 → `/machine/register`（auth key）→ MapRequest 长轮询 netmap（DiscoKey + Lite 端点上报，TS2021_LEG §3.3.1）→ DERP 连接（node key 身份）→ boringtun WG 会话；e2e 断言 **lrill→node-c WG ping 与 node-c→lrill 反向 ping（内核 ICMP 全路径）双向互通**。单测 29 个含独立 Go 语义对照（snow LE/BE nonce、nacl box 布局、ICMP checksum 内核级校验）
